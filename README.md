# 🚀 Saden WA Premium
### The Ultimate WhatsApp Marketing & Automation Command Center

Saden WA is a high-performance, enterprise-grade platform designed for marketers and businesses to manage WhatsApp campaigns with precision, security, and intelligence.

---

## 🌟 Overview
Saden WA leverages cutting-edge technology to provide a seamless experience for bulk messaging, group management, and automated customer interaction, all while prioritizing account safety and anti-ban measures.

---

## ✨ Key Features

### 📥 Intelligence & Extraction
*   **Advanced Group Member Extractor:** Instantly extract participants from any group you join with high-speed processing.
*   **Group Link Generator:** One-click invite link extraction for all your managed groups.
*   **Proactive LID Resolution:** The only engine that automatically resolves encrypted WhatsApp IDs (LIDs) into recognizable phone numbers in real-time.

### 📣 Campaign Orchestration
*   **Smart Bulk Messaging:** Reach thousands of customers with intelligent, human-like random delays to protect your numbers.
*   **Full Media Support:** Send images, videos, and documents seamlessly with your text campaigns.
*   **Advanced Scheduling:** Set your campaigns to run at specific times automatically, even when you're offline.

### 🤖 Automation & AI
*   **Smart Chatbot:** Keyword-based auto-responder with support for personal variables like `{name}` and media replies.
*   **Account Warming Engine:** Simulates human interactions to "warm up" new WhatsApp numbers and increase their sending capacity.

### 🛡️ Security & Enterprise Controls
*   **Multi-Device Management:** Connect and manage multiple WhatsApp accounts from a single dashboard.
*   **Global Licensing System:** Built-in trial management (7-day auto-lock) and secure activation via master license keys.
*   **Contact Categorization:** Organize your leads into custom categories for highly targeted marketing.

---

## 🛠️ Technology Stack
*   **Frontend:** Next.js 15 (App Router), React, Tailwind CSS (Modern Dark UI).
*   **Backend:** Node.js, Express, TypeScript.
*   **Core:** Baileys (Advanced WhatsApp Web API implementation).
*   **Database:** Micro-DB (Optimized JSON architecture for speed and simplicity).

---

## 🚀 Getting Started

1.  **Backend Setup:**
    ```bash
    cd backend
    npm install
    npm run dev
    ```
2.  **Frontend Setup:**
    ```bash
    cd frontend
    npm install
    npm run dev
    ```
3.  **Access Dashboard:** Open `http://localhost:3000` in your browser.

---

## 🔑 Licensing & Activation
This software includes a built-in security layer. After a 7-day trial period, a master activation key is required to continue usage. Contact the administrator for a license.
